# Twain Expert

Чат с экспертом по 13 книгам Марка Твена. Вы начинаете беседу на тему — хоть философскую, —
эксперт отвечает по найденным в книгах отрывкам и ставит ссылки [n]. Под каждым ответом
всегда есть источники: книга, глава, «Открыть в книге». Если подходящих отрывков нет,
эксперт так и говорит.

На каждую реплику: модель формулирует поисковый запрос с учётом диалога (HyDE) и обновляет
память задачи → векторный поиск, порог косинуса, реранкер Qwen3-Reranker → ответ модели
с историей беседы и памятью задачи.

## Запуск

Нужны Docker с Compose v2, видеокарта (Windows/Linux + NVIDIA) и ключ OpenRouter или DeepSeek
в `.env` в корне репозитория.

```bash
cd src/doc-index
docker compose up -d --build
```

1. Откройте http://localhost:5180 → вкладка «Индекс» → «Построить индекс». Первый запуск
   скачивает модели (около 4 ГБ) и книги; индекс строится около 10 минут.
2. Вкладка «Чат» → «Новый чат» или одна из предложенных тем.

## Чат

- **Список чатов** слева: создать, открыть, переименовать, удалить. Удаляется чат целиком,
  с историей. Название — тема беседы, пока вы не зададите своё.
- **Память задачи** — карточка над диалогом: тема (цель беседы), тезисы, к которым пришли,
  открытые вопросы, сводка старой части диалога. Модель ведёт её сама после каждой реплики.
  Тему можно изменить и закрепить — тогда модель её не трогает. Тезисы и вопросы можно
  править, удалять, добавлять свои (пометка «ваш», модель их не удаляет); вопрос
  переносится в тезисы кнопкой «обсудили».
- **Сжатие**: когда несжатых сообщений больше порога, старые сворачиваются в сводку,
  последние 4 остаются. В диалоге видна вся история и место сжатия.
- **Настройки чата** (свёрнуты над диалогом): модели — только просмотр; поиск (запрос,
  top-K, пороги, порядок) и порог сжатия — сохраняются в чат.
- Под ответом свёрнут блок «Как искали»: запрос, кандидаты до и после реранкинга, время.

Другие вкладки: **Поиск** — найденные отрывки без модели, **Книги** — читалка,
**Индекс** — построение индекса и состояние видеокарты.

## Настройки

Задаются в корневом `.env` и становятся настройками новых чатов. Значения порогов и top-K
подобраны командой `experiment` (`data/experiments/report.json`); переменные окружения
их переопределяют.

| Переменная | По умолчанию | Что это |
|---|---|---|
| `RAG_MODEL` | `nvidia/nemotron-3-super-120b-a12b:free` | модель ответов, памяти и сжатия; допустимо: `google/gemma-4-31b-it:free`, `qwen/qwen3.8-27b:free`, `deepseek-flash`, `deepseek-v4-pro` |
| `RERANK_MODEL` | `B-A-M-N/qwen3-reranker-0.6b-fp16` | реранкер в Ollama |
| `RETRIEVAL_QUERY` | `hyde` | что превращать в вектор: `hyde`, `en` (запрос по-английски), `raw` (реплика как есть) |
| `TOP_K_BEFORE` | из подбора | кандидатов из векторного поиска |
| `SIM_MIN` | из подбора | порог косинуса |
| `REL_MIN` | из подбора | порог оценки реранкера (0–1) |
| `TOP_K_AFTER` | из подбора | сколько отрывков максимум уходит в модель |
| `COMPRESS_AFTER` | `12` | сжимать историю, когда несжатых сообщений больше (4–50) |
| `BOOKS` | 13 книг | номера книг Project Gutenberg |

Эмбеддинги — `qwen3-embedding:4b`. Бюджет вывода модели — 100 000 токенов.

Одна реплика — 2 запроса к модели (план и ответ), при сжатии — ещё один. У бесплатных
моделей OpenRouter лимит 50 запросов в сутки.

## Команды

```bash
docker compose run --rm doc-index index               # построить индекс
docker compose run --rm -it doc-index chat            # беседа в терминале
docker compose run --rm doc-index scenario            # прогон длинных сценариев
docker compose run --rm doc-index search "вопрос"     # найденные отрывки
docker compose run --rm doc-index experiment          # подобрать пороги и top-K
docker compose run --rm doc-index stats               # что в индексе
```

`scenario` прогоняет беседы из `eval/scenarios.json` (2 сценария по 13 реплик, сжатие
после 8 сообщений) и проверяет, что у каждого ответа есть источники и ссылки, а тема
к концу беседы не потерялась. Итог — таблица в терминале и `data/scenarios-report.json`;
сами беседы видны во вкладке «Чат».

`experiment` прогоняет 52 вопроса из `eval/questions.json` (8 — без ответа в книгах)
и подбирает пороги и top-K.
