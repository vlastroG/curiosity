# Format Forge

Неделя 1, день 2. Один и тот же запрос уходит в DeepSeek **двумя** параллельными вызовами:

- **слева** — без ограничений: только сообщение пользователя, никаких дополнительных параметров;
- **справа** — с ограничениями: system prompt с описанием формата, `temperature`, `max_tokens`,
  ограничение длины в словах и стоп-последовательности (`stop`).

Панели показывают сырой текст ответа, латентность, число токенов, `finish_reason` и результат
проверки формата на клиенте.

## Ограничения

| Контрол | Куда уходит |
| --- | --- |
| Формат ответа (JSON / Markdown / HTML / YAML) | инструкция в `system`; для JSON ещё и `response_format: json_object` |
| temperature | параметр API `temperature` |
| max_tokens | параметр API `max_tokens` |
| Макс. слов | строка «Answer in no more than N words» в `system` |
| Стоп-последовательности | параметр API `stop` (до 16 строк) |

Схема полей не задаётся: проверяется только валидность формата, содержимое ответа от запуска
к запуску меняется.

Валидация: `JSON.parse` для JSON, `js-yaml` для YAML, сканер парности тегов + `DOMParser` для HTML.
Для Markdown валиден любой текст, поэтому проверка эвристическая: ищем хотя бы одну разметочную
конструкцию и отсутствие обёртки в код-фенс. Проверяется **сырой** ответ, без снятия ограждений —
именно поэтому левая панель обычно проваливает проверку, а правая проходит.

## Запуск

```bash
docker compose -f src/format-forge/docker-compose.yml up --build
```

Compose читает корневой `.env` с `DEEPSEEK_API_KEY`. Без compose:

```bash
docker build -t format-forge ./src/format-forge
```

```bash
docker run -p 5174:80 -e DEEPSEEK_API_KEY=sk-your-key-here format-forge
```

Открыть [http://localhost:5174](http://localhost:5174).

Ключ подставляется в `env-config.js` при старте контейнера, а не на этапе сборки, — поэтому один
и тот же образ работает с любым ключом.

## Ограничение по безопасности

Запросы идут из браузера напрямую, ключ виден в devtools и уходит в сеть с каждого клиента.
Для локальной учебной задачи это нормально; для публичного размещения нужен бэкенд-прокси.
