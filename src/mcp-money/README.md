# mcp-money

MCP-сервер «сколько это стоит». Определяет валюту страны, переводит суммы по курсу ЦБ РФ
и раскладывает бюджет поездки. Всю арифметику выполняет сервер, а не языковая модель.
Часть [Trip Planner](../trip-agent/README.md).

## Инструменты

| Инструмент | Вход | Выход |
|---|---|---|
| `country_currency` | `country_code` — код страны ISO | код валюты, её название, есть ли курс у ЦБ РФ; если курса нет — совет считать в USD или EUR |
| `convert` | `amount`, `from`, `to` | сумма в целевой валюте, курс, дата курса |
| `budget_split` | `total`, `currency`, `days`, `travelers` | на всех в день, на человека, на человека в день, статьи расходов |

Особенности:
- **Курсы.** Берутся с [cbr-xml-daily.ru](https://www.cbr-xml-daily.ru) — официальные курсы
  ЦБ РФ к рублю. Пары без рубля считаются через рубль. Курсы кешируются на час.
- **Валюта страны.** Справочник встроен в сервер, потому что открытые API стран закрываются
  или меняют формат.
- **Статьи расходов** — ориентир для поездки без перелёта: жильё 40 %, еда 30 %,
  транспорт 10 %, музеи 10 %, запас 10 %.
- **Округление.** Крупные суммы округляются до целых, мелкие — до копеек.

## Запуск

```bash
docker build -t mcp-money .
docker run --rm -p 8783:8080 mcp-money
```

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `8080` | порт |
| `RATES_URL` | `https://www.cbr-xml-daily.ru/daily_json.js` | источник курсов |
| `RATES_TTL` | `1h` | сколько держать курсы в кеше |
| `API_TIMEOUT` | `15s` | таймаут запроса курсов |

## Тесты

```bash
go test ./...
```

Проверяются деление на номинал (у лиры он 10), кросс-курс через рубль, кеш, округление,
разбивка бюджета и отказы на неизвестных валютах и неверных суммах.
