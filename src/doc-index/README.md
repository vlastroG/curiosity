# Twain Expert

Отвечает на вопросы о 13 книгах Марка Твена по отрывкам из них (RAG) в двух вариантах
рядом:

- **базовый RAG** — вопрос как есть, top-K ближайших отрывков, ответ модели;
- **RAG с фильтром и реранкером** — вопрос переписывается (HyDE), кандидаты проходят порог
  косинуса, реранкер Qwen3-Reranker оценивает каждый, после порога модели уходят лучшие.

Под каждым ответом свёрнут блок «Как искали»: переписанный вопрос, кандидаты до и после
реранкинга, причины отсева, время шагов. Настройки (top-K, пороги, режим запроса) меняются
прямо на странице.

## Запуск

Нужны Docker с Compose v2, видеокарта (Windows/Linux + NVIDIA) и ключ OpenRouter или DeepSeek
в `.env` в корне репозитория.

```bash
cd src/doc-index
docker compose up -d --build
```

1. Откройте http://localhost:5180 → вкладка «Индекс» → «Построить индекс». Первый запуск
   скачивает модели (около 4 ГБ) и книги; индекс строится около 10 минут.
2. Вкладка «Спросить» → задайте вопрос или нажмите пример.

## Как пользоваться

- **Спросить** — вопрос, два ответа, настройки. Клик по сноске [n] открывает отрывок.
  «Открыть в книге» ведёт в читалку на нужное место.
- **Поиск** — найденные отрывки без модели.
- **Книги** — читалка всех 13 книг.
- **Индекс** — построение индекса, состояние видеокарты.

## Настройки

Задаются в корневом `.env`. Значения по умолчанию для порогов и top-K подобраны командой
`experiment` и лежат в `data/experiments/report.json`; переменные окружения их переопределяют.
На странице их можно поменять для своих запросов.

| Переменная | По умолчанию | Что это |
|---|---|---|
| `RAG_MODEL` | `nvidia/nemotron-3-super-120b-a12b:free` | модель ответов и переписывания вопроса; допустимо: `google/gemma-4-31b-it:free`, `qwen/qwen3.8-27b:free`, `deepseek-flash`, `deepseek-v4-pro` |
| `RERANK_MODEL` | `B-A-M-N/qwen3-reranker-0.6b-fp16` | реранкер в Ollama |
| `RETRIEVAL_QUERY` | `hyde` | что искать в улучшенном режиме: `hyde`, `en` (перевод), `raw` (как есть) |
| `TOP_K_BEFORE` | из подбора | кандидатов из векторного поиска |
| `SIM_MIN` | из подбора | порог косинуса |
| `REL_MIN` | из подбора | порог оценки реранкера (0–1) |
| `TOP_K_AFTER` | из подбора | сколько отрывков максимум уходит в модель |
| `BASE_TOP_K` | `5` | отрывков в базовом режиме |
| `BOOKS` | 13 книг | номера книг Project Gutenberg |

Эмбеддинги — `qwen3-embedding:4b`. Бюджет вывода модели — 100 000 токенов.

Один вопрос — 3 запроса к модели (переписывание и два ответа), повторный — 2. У бесплатных
моделей OpenRouter лимит 50 запросов в сутки.

## Команды

```bash
docker compose run --rm doc-index index               # построить индекс
docker compose run --rm doc-index ask "вопрос"        # оба ответа в терминале
docker compose run --rm doc-index search "вопрос"     # найденные отрывки
docker compose run --rm doc-index experiment          # подобрать пороги и top-K
docker compose run --rm doc-index stats               # что в индексе
```

`experiment` прогоняет 44 вопроса по «Тому Сойеру» и «Гекльберри Финну» и 8 вопросов,
ответа на которые в книгах нет (`eval/questions.json`), сравнивает режимы и сохраняет
подобранные значения.
