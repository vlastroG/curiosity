# mcp-places

MCP-сервер «где и что посмотреть»: находит город, достопримечательности рядом и их описания.
Ключей не нужно. Часть [Trip Planner](../trip-agent/README.md), но его можно подключить
к любому MCP-клиенту.

## Инструменты

| Инструмент | Вход | Выход |
|---|---|---|
| `find_city` | `name`; `country_code` — если название неоднозначно | город: координаты, страна и её код ISO, часовой пояс; другие места с тем же названием |
| `sights` | `latitude`, `longitude`; `radius_km` 1–10 (5); `limit` 1–20 (12) | статьи Википедии о местах рядом: `page_id`, язык, название, короткое описание, расстояние |
| `sight_info` | `page_id`, `lang` (`ru`/`en`) из `sights` | вступление статьи (до 1200 символов) и ссылка |

Источники:
- город — [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api) на русском;
- места — геопоиск Википедии: русской, а если в ней рядом пусто — английской.

Места берутся из Википедии, а не из OpenStreetMap, потому что у статьи есть описание, по
которому модель выбирает места под интересы. Весь текст очищается от управляющих символов,
ударений и скобок с транскрипциями и обрезается по длине.

## Запуск

```bash
docker build -t mcp-places .
docker run --rm -p 8781:8080 mcp-places
```

Без контейнера: `PORT=8781 go run .`

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `8080` | порт |
| `API_TIMEOUT` | `15s` | таймаут запроса к источнику |
| `GEOCODE_URL` | Open-Meteo | адрес геокодера |
| `WIKI_URL` | `https://%s.wikipedia.org/w/api.php` | шаблон API Википедии, `%s` — язык |

Транспорт — Streamable HTTP без сессий на `/mcp`, здоровье — `GET /health`.

## Тесты

```bash
go test ./...
```

Геокодер и Википедия подменяются `httptest`. Проверяются запасная английская Википедия,
сортировка по расстоянию, очистка текста и отказы на пустых или неверных аргументах.
