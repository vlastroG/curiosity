# mcp-pipeline

MCP-сервер с инструментами, из которых складывается конвейер «найти на Hacker News →
законспектировать по-русски → сохранить в HTML». Порядок вызовов определяет клиент.
Штатный клиент — агент [HN Digest Agent](../pipeline-agent/README.md), где порядок выбирает
языковая модель. Подойдёт и любой другой MCP-клиент.

## Инструменты

| Инструмент | Вход | Выход |
|---|---|---|
| `hn_search` | `query` — английские ключевые слова; `topic` — тема пользователя, станет заголовком; `limit` 1–10 (5); `days` — период в днях; `sort` — `relevance` или `date` | `search_id`, `sha256`, список историй |
| `summarize` | `search_id` из `hn_search` | `summary_id`, `sha256`, `source_id`, `source_sha256`, обзор |
| `save_to_file` | `summary_id` из `summarize`; `filename` — короткое имя латиницей | имя файла, размер, `sha256`, id и хеши всех звеньев |
| `list_files` | — | опись сохранённых конспектов |

Каждый результат приходит дважды: текстом для модели и в `structuredContent` для программ.

## Как данные идут по цепочке

```
hn_search ──► artifacts/src_….json ──► summarize ──► artifacts/sum_….json ──► save_to_file ──► out/….html
               sha256 выдачи            (source_sha256 = sha выдачи)          (сверяет оба хеша)
```

- Инструменты обмениваются id артефактов, а не текстом. Выдача с комментариями может занимать
  сотни строк, и модели не нужно переносить её из вызова в вызов.
- У каждого артефакта хранится sha256 содержимого. `summarize` записывает хеш выдачи, по которой
  сделан конспект. `save_to_file` проверяет, что выдача с тех пор не изменилась.
- Каждый инструмент принимает только артефакт своего типа. Если передать `search_id` в
  `save_to_file`, текст вместо id или путь, инструмент откажет с понятной причиной.
- В конце HTML есть блок «Происхождение»: запрос → id и хеш выдачи → id и хеш конспекта.

## Что делает каждый шаг

- **hn_search** обращается к [Algolia HN Search API](https://hn.algolia.com/api) (без ключа).
  Для каждой истории он забирает до 8 комментариев верхнего уровня. Текст очищается
  от HTML и управляющих символов и обрезается по длине.
- **summarize** передаёт материалы модели внутри блока `<hn_data>` как недоверенные данные.
  Ответ — JSON на русском: обзор, перевод заголовков, конспект и тезисы по каждой истории.
  Если ответ не разобрался или написан не на русском, модель получает одну повторную попытку.
  Истории, которых нет в выдаче, отбрасываются; пропущенные помечаются.
- **save_to_file** сохраняет самодостаточный HTML: встроенные стили, без скриптов и внешних
  ресурсов, светлая и тёмная тема. Затем пересобирает `index.html` и `index.json`.
  Имя файла — `[a-z0-9-]` плюс дата. Путь всегда внутри каталога вывода.

## Запуск

Обычно сервер запускается из compose агента:

```bash
cd ../pipeline-agent && docker compose up -d --build mcp-pipeline
```

Отдельно:

```bash
docker build -t mcp-pipeline .
docker run -d -p 8765:8080 --env-file ../../.env -v pipeline-data:/data mcp-pipeline
```

Транспорт — Streamable HTTP без сессий, ответ приходит обычным JSON:

```bash
curl -s -X POST http://localhost:8765/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'MCP-Protocol-Version: 2025-11-25' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"hn_search","arguments":{"query":"rust web","days":365}}}'
```

## Конфигурация

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PIPELINE_MODEL` | `nvidia/nemotron-3-super-120b-a12b:free` | модель для `summarize`; список — в [README агента](../pipeline-agent/README.md#модели) |
| `OPENROUTER_API_KEY`, `DEEPSEEK_API_KEY` | — | ключи провайдеров |
| `PORT` | `8080` | порт HTTP |
| `DATA_DIR` | `/data` | артефакты: `DATA_DIR/artifacts` |
| `OUT_DIR` | `DATA_DIR/out` | HTML-конспекты |
| `HN_API_URL` | `https://hn.algolia.com` | адрес HN Search API |
| `HN_TIMEOUT` | `20s` | таймаут запроса к HN |
| `LLM_TIMEOUT` | `4m` | таймаут ответа модели |

Модель читается при старте. С неизвестной моделью или без ключа сервер не запускается.

## Логи

Каждый вызов инструмента оставляет строку: что пришло, что ушло, хеши и время.

```
mcp-pipeline шаг hn_search ← query="rust web" limit=5 days=365 sort=relevance → src_de4db0807e (5 историй, sha e95e5f63986b) 2.0s
mcp-pipeline шаг summarize ← src_de4db0807e (sha e95e5f63986b) → sum_f379b02ef1 (5 историй, пропущено 0, sha 67fd743e6182, модель …) 23.3s
mcp-pipeline шаг save_to_file ← sum_f379b02ef1 (sha 67fd743e6182) → out/rust-web-20260924-162346.html (13479 байт, sha c36e07e32bc4) 0.0s
```

## Тесты

```bash
go test ./...
```

HN API подменяется `httptest`, модель — заглушкой. Инструменты вызываются настоящим
MCP-клиентом через транспорт в памяти. Тесты проверяют цепочку целиком, отказы на
чужих и выдуманных id и на подменённой выдаче, санитизацию имени файла, экранирование
HTML и обезвреживание комментариев с попытками инъекций.
